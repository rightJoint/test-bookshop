Проект Bookshop

Необходимо разработать простенький проект книжного магазина. Проект должен быть подготовлен и сконфигурирован в Dockerfile.

Требования к Docker имиджу

- Необходимо использовать имедж Ubuntu.  (На пример: mrxder/docker-apache-php7.2-mysql-phpmyadmin либо любой удобный)
- В образ должен быть установлены mc, openssh-server
- Для Apache должен быть создан виртуальный хост: bookshop.loc
- Для ssh подключения должен быть создан юзер: admin,   пароль: trust

Описание проекта

Книжный магазин содержит книги. Книга имеет имя и цену. Каждая книга может иметь один и более авторов и относиться лишь к одной категории. 
Также книга имеет статус из 3 значений (В наличии, Нет на складе, Снято с продажи)

Необходимо реализовать отчет в виде аккордеона: сколько книг содержится в каждой категории и какая сумма книг в данной категории. При раскрытии аккордеона должны вывестись книги данной категории.


Критерии приемки

- Для проверки должен быть передан Dockerfile c конфигурацией.
- Папка с проектом (её нужно указать в Dockerfile для копирования).
- Папка с виртуальным хостом (её нужно указать в Dockerfile для копирования).
- Параметры команды run с пробросом портов для http и ssh.
- БД должны быть нормализирована.
- Файл install.php для  загрузки тестовых данных.
- Иерархия классов по возможности должна соответствовать SOLID принципам.
